# Security

cc-session-manager runs on your own computer, listens only on `127.0.0.1`, and acts on your own Claude Code sessions. The safety rules for actions, and what the tool reads, keeps, and sends, are in the [release notes](docs/release-notes.md).

## Reporting a vulnerability

Please report a vulnerability privately, through GitHub's **Report a vulnerability** button on this repository's [Security tab](https://github.com/napalmCore/cc-session-manager/security). Don't open a public issue for it.

Include what you found, how to reproduce it, and which version or commit you used. You'll get an answer in the advisory itself.

## Supported versions

Only the latest release gets fixes.

cc-session-manager is an independent tool. It isn't made, endorsed, or supported by Anthropic. Report problems in Claude Code itself to Anthropic.
